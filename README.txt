Quick setup:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Replace Jordan Lee with your name.
4. Replace JL with your initials.
5. Edit About, Skills, Projects, Services and Contact.
6. Replace demo project links (#) with real project URLs.
7. Put your own images in assets/ if needed.
8. Save and refresh.

No React, Node.js or build tool is required.
